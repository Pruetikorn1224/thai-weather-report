# Thai Water Report

วันที่อัพเดทล่าสุด: 2026-8-14

พยากรณ์อากาศ 24 ชั่วโมงข้างหน้า ประเทศไทยยังคงมีฝนตกหนักบางแห่ง โดยมีฝนตกหนักมากบริเวณภาคตะวันออก เนื่องจากร่องมรสุมพาดผ่านประเทศเมียนมา ประเทศลาวตอนบน และประเทศเวียดนามตอนบน ประกอบกับมรสุมตะวันตกเฉียงใต้ที่พัดปกคลุมทะเลอันดามัน ประเทศไทย และอ่าวไทยมีกำลังค่อนข้างแรง ขอให้ประชาชนในบริเวณดังกล่าวระวังอันตรายจากฝนตกหนักและฝนที่ตกสะสมซึ่งอาจทำให้เกิดน้ำท่วมฉับพลันและน้ำป่าไหลหลาก โดยเฉพาะพื้นที่ลาดเชิงเขาใกล้ทางน้ำไหลผ่านและพื้นที่ลุ่ม รวมถึงน้ำล้นตลิ่งในบริเวณภาคตะวันออกเฉียงเหนือสำหรับคลื่นลมบริเวณทะเลอันดามันตอนบนมีกำลังค่อนข้างแรง โดยมีคลื่นสูง 2-3 เมตร บริเวณที่มีฝนฟ้าคะนองมีคลื่นสูงมากกว่า 3 เมตร ขอให้ชาวเรือเดินเรือด้วยความระมัดระวังและหลีกเลี่ยงการเดินเรือในบริเวณที่มีฝนฟ้าคะนอง ส่วนเรือเล็กบริเวณทะเลอันดามันตอนบน ควรงดออกจากฝั่ง
