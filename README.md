# Thai Water Report

วันที่อัพเดทล่าสุด: 2026-8-8

พยากรณ์อากาศ 24 ชั่วโมงข้างหน้า ประเทศไทยมีฝนตกหนักหลายพื้นที่ และมีฝนตกหนักมากบางพื้นที่ในภาคเหนือ ภาคตะวันออกเฉียงเหนือ และภาคตะวันออก เนื่องจากร่องมรสุมพาดผ่านภาคเหนือตอนบน และภาคตะวันออกเฉียงเหนือตอนบน เข้าสู่หย่อมความกดอากาศต่ำบริเวณอ่าวตังเกี๋ย ประกอบกับมรสุมตะวันตกเฉียงใต้ที่พัดปกคลุมทะเลอันดามัน ประเทศไทย และอ่าวไทยมีกำลังค่อนข้างแรง ขอให้ประชาชนในบริเวณดังกล่าวระวังอันตรายจากฝนตกหนักถึงหนักมากและฝนที่ตกสะสม ซึ่งอาจทำให้เกิดน้ำท่วมฉับพลันและน้ำป่าไหลหลาก โดยเฉพาะพื้นที่ลาดเชิงเขาใกล้ทางน้ำไหลผ่านและพื้นที่ลุ่มสำหรับคลื่นลมบริเวณทะเลอันดามันตอนบนและอ่าวไทยตอนบนมีกำลังค่อนข้างแรง โดยมีคลื่นสูง 2-3 เมตร บริเวณที่มีฝนฟ้าคะนองมีคลื่นสูงมากกว่า 3 เมตร ขอให้ชาวเรือเดินเรือด้วยความระมัดระวังและหลีกเลี่ยงการเดินเรือในบริเวณที่มีฝนฟ้าคะนอง ส่วนเรือเล็กบริเวณทะเลอันดามันตอนบน และอ่าวไทยตอนบนควรงดออกจากฝั่งอนึ่ง พายุไต้ฝุ่น “ดอลฟิน” บริเวณมหาสมุทรแปซิฟิก ด้านตะวันตกของจังหวัดโอกินาวะ ประเทศญี่ปุ่น และคาดว่าจะเคลื่อนขึ้นฝั่งบริเวณมณฑลเจ้อเจียง ประเทศจีนในช่วงวันที่ 9-10 ส.ค. 69 โดยพายุนี้ไม่เคลื่อนเข้าสู่ประเทศไทย ขอให้ผู้ที่จะเดินทางไปบริเวณดังกล่าวตรวจสอบสภาพอากาศก่อนออกเดินทางไว้ด้วย
