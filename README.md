# Thai Water Report

วันที่อัพเดทล่าสุด: 2026-8-5

พยากรณ์อากาศ 24 ชั่วโมงข้างหน้า ประเทศไทยจะมีฝนเพิ่มขึ้น โดยภาคตะวันออกเฉียงเหนือมีฝนตกหนักถึงหนักมากบางแห่ง ส่วนภาคเหนือ ภาคกลาง ภาคตะวันออก และภาคใต้ มีฝนตกหนักบางพื้นที่ เนื่องจากร่องมรสุมพาดผ่านภาคเหนือตอนบนและประเทศลาวตอนบน เข้าสู่หย่อมความกดอากาศต่ำบริเวณชายฝั่งประเทศเวียดนามตอนบน ประกอบกับมรสุมตะวันตกเฉียงใต้กำลังปานกลางที่พัดปกคลุมทะเลอันดามัน ประเทศไทย และอ่าวไทยมีกำลังแรงขึ้น ขอให้ประชาชนในบริเวณดังกล่าวระวังอันตรายจากฝนตกหนักถึงหนักมากและฝนที่ตกสะสม ซึ่งอาจทำให้เกิดน้ำท่วมฉับพลันและน้ำป่าไหลหลาก โดยเฉพาะพื้นที่ลาดเชิงเขาใกล้ทางน้ำไหลผ่านและพื้นที่ลุ่ม  สำหรับคลื่นลมบริเวณทะเลอันดามันและอ่าวไทยมีกำลังแรงขึ้น โดยทะเลอันดามันตอนบนมีคลื่นสูง 2-3 เมตร บริเวณที่มีฝนฟ้าคะนองมีคลื่นสูงมากกว่า 3 เมตร ส่วนทะเลอันดามันตอนล่างและอ่าวไทยตอนบนมีคลื่นสูงประมาณ 2 เมตร บริเวณที่มีฝนฟ้าคะนองคลื่นสูงมากกว่า 2 เมตร ขอให้ชาวเรือเดินเรือด้วยความระมัดระวังและหลีกเลี่ยงการเดินเรือในบริเวณที่มีฝนฟ้าคะนอง ส่วนเรือเล็กบริเวณทะเลอันดามันตอนบนควรงดออกจากฝั่งไว้ด้วย  อนึ่ง พายุดีเปรสชันบริเวณทะเลจีนใต้ ได้ทวีกำลังแรงขึ้นเป็นพายุโซนร้อน “คูจิระ” แล้ว และกำลังเคลื่อนไปทางตอนบนของประเทศฟิลิปปินส์ ขอให้ผู้ที่จะเดินทางไปบริเวณดังกล่าว ตรวจสอบสภาพอากาศก่อนออกเดินทางด้วย โดยพายุนี้ไม่เคลื่อนเข้าสู่ประเทศไทย
